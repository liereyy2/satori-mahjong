CPU为牌桌通道提交耗时；GPU为异步时间戳区间，可能包含提交等待。报告中的帧间隔受Fabric测试调度器影响，不能取倒数当作实际游戏FPS。集成服tick仅覆盖空闲物理桌，没有活动云端会话。Projection报告仅覆盖复制与序列化，输出字节量前后一致，不包含网络、HTTP或推理。

在图形环境运行 `./gradlew runTablePerformance` 和 `./gradlew runProjectionPerformance` 可复核当前实现。完整测量背景保存在原 satori 总仓库的内部 Minecraft 文档分区。旧版对照使用独立解包的上述Git版本源码、同一基准夹具与采样逻辑，排除只适用于新版的视锥回归检查。
