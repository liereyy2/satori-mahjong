# SatoriMahjong 日语鸣牌样音

语音合成：**VOICEVOX:四国めたん**。这是新声音的试听稿，尚未加入发布的模组。

两条试听均依次播放 **碰 → 杠 → 立直**，每句之间间隔 0.65 秒。

| 版本 | 连续试听 | 碰 | 杠 | 立直 |

A 使用正常发声风格，B 使用あまあま风格。两组都保持自然语速，单独控制音节长度；整体音高略降，减少拖尾。建议用相同设备和音量比较，重点听是否清楚、自然，以及连续播放时是否刺耳或拖沓。

目录保留单句 WAV、Ogg、未后处理的 raw.wav、调音前后的 query.json 和测量 manifest。连续试听另有无损 WAV。生成脚本及复现命令见内部文档站的 Minecraft 实现分区。
